# PHASE 16 — Mobile Reports

Build lightweight operational reports.

Do not attempt to reproduce the entire Admin ERP BI system.

Useful mobile reports:

- Today's sales
- Branch sales
- Inventory summary
- Stock aging
- Pending repairs
- Pending transfers
- Pending approvals
- Customer summary

Use charts where they improve understanding.

Respect:

- Tenant
- Branch
- Role
- Permission

Do not expose financial or business-sensitive information without authorization.
