# PHASE 4 — Jewellery Search & Digital Passport

Build mobile jewellery item search and the complete Digital Jewellery Passport.

## Search

Allow employees to search using:

```text
Item ID
Barcode
QR Code
RFID
Product Code
Design Code
```

Support filters:

```text
Branch
Location
Category
Metal
Purity
Status
Price Range
```

## Jewellery Detail

Create a premium mobile detail page.

Display:

```text
Jewellery Image

Item ID
Product
Design
Category

Metal
Purity
Gross Weight
Net Metal Weight
Stone Weight

RFID
Barcode
QR Code

Current Price
Current Location
Current Status
```

## Digital Passport

Create sections:

### Product

Product/design information.

### Metal

Purity and weight.

### Gemstones

Diamond/gemstone information.

### Certificate

Certificate number and document/image.

### Location

Current branch and physical location.

### Lifecycle

Display a timeline:

```text
Purchased
   ↓
Quality Checked
   ↓
RFID Tagged
   ↓
Warehouse
   ↓
Branch
   ↓
Showroom
   ↓
Counter
```

### History

Display:

- Transfers
- Repairs
- Sales
- Exchange
- Buyback

## Actions

Depending on permissions:

```text
Transfer
Reserve
Start Repair
View Certificate
View History
```

Do not allow actions that backend permissions prohibit.
